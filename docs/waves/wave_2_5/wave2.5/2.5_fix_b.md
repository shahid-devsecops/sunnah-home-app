Repository:
~/firdous/veedu-home-soul

Current problem:

The authenticated user is Shahid.

However, after login the Home UI automatically opens with:

Household | Usman (Child)

and Usman is selected.

This prevents Shahid from naturally managing his own:
- tasks
- Salah
- Hifz
- habits
- personal/member data

The previous fix correctly established that Household is represented by:
selectedMemberId === undefined

BUT the current product needs a stronger distinction:

ME
HOUSEHOLD
OTHER FAMILY MEMBER

==================================================

Default authenticated experience:

LOGIN AS SHAHID

resolve Shahid's linked FamilyMember

selectedMemberId = ShahidMemberId

[ Shahid ] [ Household ] [ Wife ] [ Usman ]

or an equivalent existing layout.

Household is explicit.

Other members are explicit.

A child MUST NEVER be selected automatically.
